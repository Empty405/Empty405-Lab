# Responsible Disclosure

If research identifies a credible security vulnerability:

1. Preserve evidence.
2. Do not access additional third-party data.
3. Stop testing once sufficient evidence exists.
4. Identify the appropriate responsible disclosure channel.
5. Report the issue privately.
6. Avoid publishing actionable exploitation details while remediation is pending.
7. Document dates and responses.
8. Publish only what can be responsibly disclosed.
