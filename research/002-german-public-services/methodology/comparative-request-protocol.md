# Comparative Request Protocol

## Principle

Equivalent institutions receive equivalent core questions.

## Before sending

For each request record:

- exact request version
- target institution
- communication channel
- UTC timestamp

## During collection

Do not modify an already-sent request.

Record:

- automatic acknowledgement
- first human response
- substantive response
- referrals
- clarification requests
- final response

Preserve original responses.

## Evaluation

Response time and response quality are separate variables.

Do not infer:

- corruption
- discrimination
- hostility
- institutional intent

from response time alone.

## Repetition

A single response is an observation.

Repeated comparable observations are required before describing a
systematic institutional difference.

## Evidence integrity

Original responses should be preserved privately.

Public research material must remove personal identifiers and unrelated
personal information before publication.
