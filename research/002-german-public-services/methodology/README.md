# Methodology

Every claim should be connected to evidence.

## Evidence ladder

OBSERVATION
    ↓
HYPOTHESIS
    ↓
REPRODUCED
    ↓
CORROBORATED
    ↓
CONFIRMED FINDING

## Evidence sources

Possible sources include:

- legislation
- official administrative documentation
- privacy policies
- terms of use
- technical documentation
- application-store documentation
- public web interfaces
- institutional responses
- anonymized first-party case material
- reproducible tests on authorized accounts

## Core rule

Always record alternative explanations.

A result that contradicts the initial hypothesis must also be documented.
Negative findings are valid research results.
